# TANK FIELD · 装甲前线

HTML Canvas 坦克大战，支持单人和 1～4 人合作。随机地图无限循环，四款战车可选，包含精英怪、Boss、道具与移动端双摇杆。

## 启动与部署

安装 Node.js 18+，在项目目录执行，无第三方依赖：

```sh
npm start
```

默认访问 http://localhost:8002。服务器监听 0.0.0.0，开放端口后可通过服务器地址访问。Linux 可用 `PORT=8002 npm start` 覆盖配置端口；PowerShell 可先执行 `$env:PORT=8002`。现有 `start.bat` 使用 WSL 启动。

Nginx 示例见 [deploy/nginx.conf](deploy/nginx.conf)，已关闭 SSE 缓冲与代理缓存。房间保存在单个 Node 进程内，重启服务会清空房间。

前后端分离时，将 `config.js` 的 `serverURL` 填为后端公开地址，例如 `https://battle-api.example.com`，留空使用当前网站。后端允许任意来源的 CORS、OPTIONS 预检与 SSE。HTTPS 页面需要 HTTPS 后端。

单人可直接打开 `index.html`。独立静态前端需要 `index.html`、`style.css`、`config.js`、`engine.js`、`network.js`、`touch.js`、`game.js`。

## 数值配置

所有玩法平衡与联机参数集中在 [config.js](config.js)，浏览器和服务器共用。修改后重启服务并刷新页面；前后端分离时两端部署同一份配置。时间单位为秒，速度单位为像素/秒；以 Ms 结尾的参数使用毫秒。

| 配置 | 用途与默认值 |
| --- | --- |
| `bulletSpeedMultiplier` | 全体弹速倍率，默认 `2 / 3`，比原版降低 1/3；车型和敌军中的 bulletSpeed 为基础弹速 |
| `supplies` | 开局 1 个道具；首次及后续刷新均为 10 秒；增益 5 秒，维修 40 点 |
| `multiplayer.playerHp` | 按 1、2、3、4 人房间设置玩家血量倍率，默认 `[1,1,1,1]` |
| `multiplayer.enemyHp / eliteHp / bossHp` | 按人数设置普通怪、精英、Boss 血量倍率，默认均为 `[1,1,1,1]` |
| `vehicles` | 四款战车的血量、速度、伤害、射击间隔、基础弹速及炮管数 |
| `enemies` | 三类敌军的血量系数、速度系数、射击间隔系数、伤害、弹速及掉落率 |
| `waves / ai` | 敌军数量、难度成长、精英/Boss 周期、清场/重开倒计时、AI 行为 |
| `weapons / physics / map` | 炮弹寿命、散射角、碰撞参数、地形与出生点 |
| `network / touch / render` | 联机频率和超时、预测/插值、摇杆死区、画面特效预算 |

例如，`playerHp: [1, 1.5, 2, 2.5]` 表示房间有 1～4 人时，玩家血量分别乘这些倍率。加入或离开时保持当前血量比例，阵亡坦克不会因此复活；单人模式使用基础血量。

## 操作与规则

- 电脑：WASD / 方向键移动；鼠标瞄准，按住左键或空格开火；Esc / P 打开菜单。
- 手机：左摇杆移动，右摇杆拖动瞄准并开火，支持双指同时操作。横屏让战场占满可用视口；部署时尝试浏览器全屏，不支持的浏览器使用视口布局。
- 清空敌军后 3 秒进入新地图；清场倒计时可以继续移动和拾取道具。全队阵亡后 3 秒以同一地图重新开始本关。
- 每 5 关额外出现 1 个三联射击精英，每 10 关额外出现 1 个五发扇形射击 Boss；第 10 关同时有精英和 Boss。
- 普通怪掉落率 5%，精英 40%，Boss 100%。Boss 必掉奖励不受当前道具数量上限阻止。
- 砖墙可破坏，钢墙永久阻挡，水域限制通行。临时增益接触生效，合作模式无友伤。

## 多人同步

服务器统一裁定移动、碰撞与伤害。客户端回放近期真实输入，按操作确认校正位置；松手优先发送，待发送队列只保留最新操作。清场阶段继续预测移动，换关/同图重开按新回合清除历史操作，避免旧请求进入新关卡。

首次进入、重连与换关发送完整地形；协议 v3 的砖墙受损和移除使用增量补丁，落后客户端重新取得完整地形。慢连接跳过过时状态；地面与草丛分开缓存，出生点可达区域在地形未变时复用。仍保留旧协议兼容。
