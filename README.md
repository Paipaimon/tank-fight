# TANK FIELD · 装甲前线

HTML Canvas 坦克大战。WASD 移动，鼠标旋转炮塔并射击；支持单人演练和 1–4 人局域网或服务器联机合作闯关。清空敌人后自动进入下一张随机关卡，难度逐步增加。

## 开始游戏

**单人模式**：直接双击 `index.html`，选择单人演练即可。无需安装，也无需联网。

**多人模式**：需要 Node.js 18 或更高版本，无第三方依赖，无需 `npm install`。

```sh
npm start
```

Windows 也可以双击 `start.bat`。然后访问终端显示的 `http://localhost:8002`。

1. 一位玩家启动服务并创建房间，获得六位房间码。
2. 同一局域网内的好友打开终端列出的局域网地址，例如 `http://192.168.1.10:8002`。
3. 好友输入相同房间码加入；每个房间最多 4 位真人玩家，共同对抗 AI 敌人。
4. 本机测试时也可以打开两个浏览器标签页，分别创建和加入同一房间。

需要更换端口时，PowerShell 可执行 `$env:PORT=3001` 后再运行 `npm start`。

## 服务器部署

将项目文件上传至装有 Node.js 18+ 的服务器，在项目目录启动，无需安装第三方依赖：

```sh
PORT=8002 npm start
```

服务监听 `0.0.0.0`，可通过 `http://服务器IP:8002` 访问。开放对应端口后，不同网络的玩家打开相同地址即可加入同一房间；使用域名反向代理时也可直接访问域名。

Nginx 配置示例见 `deploy/nginx.conf`。该配置已关闭 SSE 缓冲和代理缓存，并延长流式连接超时，避免游戏状态在代理中积压。域名使用 HTTPS 时，在反向代理配置证书，游戏服务仍可在内部使用 HTTP。

房间保存在单个 Node 进程内。部署一份服务进程即可；重启会清空房间。

### 前后端分开部署

服务默认允许任意来源（`Access-Control-Allow-Origin: *`），支持 `OPTIONS` 预检、JSON 操作接口和 SSE 状态流。玩家身份仍通过房间令牌校验，不使用浏览器 Cookie。

如果 HTML 与游戏服务位于不同域名或端口，在前端的 `config.js` 中填写后端的公开地址：

```js
window.TANK_SERVER_URL = 'https://battle-api.example.com';
```

页面所有开房、加入、操作、离开和状态流都会连接该地址。前端使用 HTTPS 时，后端公开地址也应使用 HTTPS，避免浏览器阻止混合内容。将该值留空即可使用当前网站地址，适合 Node 直接托管或 Nginx 统一代理整个游戏。

独立静态前端需要上传 `index.html`、`style.css`、`config.js`、`engine.js`、`network.js`、`game.js`。

## 操作与规则

- **W / A / S / D 或方向键**：移动坦克；鼠标位置控制炮塔方向。
- **鼠标左键或空格**：射击，可按住连续开火。
- **Esc 或 P**：打开游戏菜单；单人暂停，联机房间继续运行。
- 消灭当前关卡的全部敌人后，短暂倒计时并生成下一张地图。
- 砖墙可以打碎；钢墙是永久掩体；水域限制坦克通行。
- 维修、护盾、连射、散射、加速道具接触即拾取；临时增益显示在界面中。
- 队友尚存时，阵亡玩家等待队友清场；全队阵亡后倒计时 3 秒，以相同地图重新开始当前关卡。清场则进入下一关，全员重新部署。
- 护盾、连射、散射和加速统一持续 5 秒；维修即时恢复 40 点装甲。多人合作不互相造成伤害。

## 多人同步优化

地图只在首次进入、断线重连、地形受损或换关时发送，其余更新只传动态状态。数值精度和事件去重减少传输量，慢连接跳过过期更新，操作序号避免旧请求覆盖新操作。

本地战车即时预测移动并按服务器位置校正，队友、敌军和炮弹通过短缓冲平滑显示；停止收到状态时预测也会停止。服务器仍决定碰撞、伤害、道具和关卡结果。地形与草丛使用绘制缓存，碰撞检测按地图格子查询，状态栏只在显示内容变化时更新。

## 项目结构

- `index.html`、`style.css`、`game.js`：界面、Canvas 绘制与输入控制。
- `config.js`：独立部署前端时使用的游戏服务地址；留空使用当前网站。
- `deploy/nginx.conf`：保留实时 SSE 状态流的反向代理配置示例。
- `engine.js`：浏览器与服务器共用的游戏模拟、地形、AI 和碰撞。
- `network.js`：动态状态合并、本地移动预测、位置校正和其他实体的平滑显示。
- `server.js`：Node 原生 HTTP 服务、房间管理、SSE 状态同步与输入接口。
- `engine.test.js`、`network.test.js`、`server.test.js`：游戏规则、画面同步和真实 HTTP 多客户端联机测试。

```sh
npm test
```

多人房间由服务器统一运行模拟，客户端只发送操作。掉线后输入立即停止；15 秒未重连会移出房间，空房间 60 秒后清理。
